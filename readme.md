# Timesheet Converter

Timesheet Converter is a small tool that converts timesheet data from Excel files into cleaner, structured one.

It is designed to handle messy real-world timesheets and turn them into consistent, machine-friendly data.

---

## Features

- ✅ Read timesheet data from `.xlsx` / `.xls` files
- ✅ Export it to cleaner one
- ✅ Support multiple timesheet formats

---

## Use Cases

- There is only one use case.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/timesheet-converter.git
cd timesheet-converter
yarn install
// Configure src/configs.ts based on your file
yarn start
```
